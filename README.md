*SMART CASH*

Deskripsi Singkat
Smart Cash adalah aplikasi kasir digital berbasis teks menggunakan bahasa pemrograman Pascal. Program ini dirancang untuk memudahkan proses penghitungan total belanja, penerapan diskon otomatis berdasarkan besaran nominal belanja, serta dilengkapi dengan menu interaktif dan kontrol perulangan.

Fitur-Fitur Utama & Logika Program
1. Menu Interaktif (Repeat-Until): 
   - Menggunakan struktur perulangan repeat-until pada menu utama agar program terus berjalan hingga pengguna memilih opsi keluar.
2. Transaksi Penjualan (For-Do & If-Else): 
   - Pengguna dapat menginput jumlah jenis barang yang dibeli.
   - Program menggunakan perulangan for-to-do untuk meminta input nama dan harga barang secara berulang.
   - Menerapkan percabangan if-then-else untuk memberikan diskon 10% jika total belanja melebihi Rp 100.000.
3. Kontrol Perulangan & Peloncatan (Continue): 
   - Menggunakan perintah peloncatan continue jika pengguna ingin membatalkan transaksi di awal.
